e_learnX — Collaborative E-Learning Platform (Sprint 5: Communication & Notifications)

Welcome to the repository for E-LearnX, an open-source, modern web-based Learning Management System (LMS) developed collaboratively by a 12-student team following the Scrum methodology

This repository documents our academic project work, focusing specifically on Sprint 5: Communication & Social Interactions.

Project Team & Context

Academic Context: Developed as part of a collaborative group project at the Institut Supérieur d'Informatique de Mahdia (ISIMa).
Team Size: 12-member multidisciplinary Scrum team
Methodology: Strict adherence to Scrum (2-week sprints, daily stand-ups, backlog grooming, and sprint reviews).

My Responsibilities: Sprint 5 (Communication & Notifications)

As the Sprint 5 Lead Developer (alongside team member Mariem Halouani), my core focus was breaking down the isolation of online learning by building social tools and real-time communication modules.
Key Features Implemented in Sprint 5:

1.Pedagogical Forum:
    Designed discussion threads linked to specific courses.    
    Enabled students and teachers to create posts, reply to threads, and handle collaborative      Q&A.
2.Internal Messaging System:
     Built a direct private messaging interface allowing secure teacher-student                    communication.   
     Implemented inbox views, message previews, and conversation filtering
3.Real-Time Notification System:
     Developed an in-app notification center tracking system events (e.g., new grades,             assignment deadlines, forum replies, and announcements).   
     Integrated backend triggers to alert users instantly upon state changes.
     
 Tech Stack Overview :
 
 Frontend: HTML5, CSS3 / Modern CSS Architecture, JavaScript
 Backend: Node.js, Express.js, PHP/MySQL integration for legacy data handling
 Real-Time & Communication: WebSockets (Socket.io) / Event-driven notification triggers
 Architecture: Modular, component-driven design built collaboratively under strict sprint deadlines.
